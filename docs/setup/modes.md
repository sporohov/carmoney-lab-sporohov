code - режим для редактирования файлов / кодогенерации.
Запросил разрешение на редактирование файла.

Ask: режим обсуждения/разговора/опроса.
Одна из фраз модели:
"Я в режиме Ask — редактировать файлы не могу"

Plan - подготовительный режим, перед реализацией задачи.
Формирует первоначальный чек-лист план, по которому далее пойдет при реализации. используется не так часто.

Debug — режим для поиска причины ошибки и её исправления. Агент может изучить код и логи, проверить гипотезы и внести исправление.
